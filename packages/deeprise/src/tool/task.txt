Launch a new agent to handle complex, multistep tasks autonomously.

When using the Task tool, you must specify a subagent_type parameter to select which agent type to use.

## Who may use Task

- **super agent**: coordinates all subagents (primary orchestrator)
- **user_level_test agent**: may spawn focused subagents for parallel flow testing

All other subagents must NOT use Task — report results to super instead.

## When super should use Task

- After planning → orchestration, security_engineer, devops_engineer, developer
- After implementation → code_reviewer, test, runtime_qa, user_level_test
- After any gate failure → appropriate fix agent, then re-run failed gates
- **Never skip user_level_test** for app changes before reporting completion

## When NOT to use Task

- Reading files → Read/Glob
- Searching code → Grep
- These are faster than spawning agents

## Agent chaining rules

- Only **super** orchestrates the pipeline. Subagents do NOT chain to other subagents (except user_level_test spawning test subagents).
- Do NOT assume automatic handoff — super must explicitly invoke the next agent.
- When delegating, include: TODO list, prior agent evidence blocks, failure output, and what to verify.

Usage notes:
1. Launch multiple agents concurrently when tasks are independent
2. Subagent output is returned to the caller, not shown to the user directly
3. Provide detailed prompts with exact verification commands expected
4. Require subagents to return VERIFICATION EVIDENCE blocks with real command output
5. Do not trust PASS/READY claims without evidence — validate before proceeding
6. If the task changes code, the fix agent must re-run appropriate tests before reporting

Example (super delegating user-level test):
```
Task(
  subagent_type="user_level_test",
  description="Gate app readiness",
  prompt="Web app at packages/myapp. Run: cd packages/myapp && bun run test:e2e. Verify all primary flows. Return APP READINESS STATUS with VERIFICATION EVIDENCE for every command. Playwright exit 0 required for READY."
)
```
